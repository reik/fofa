# Accessibility (WCAG 2.1)

- All UI code must comply with WCAG 2.1 AA
- Check for: missing alt on images, buttons/links with no accessible name, inputs without labels, onClick on non-interactive elements (div/span), outline-none without a focus-visible replacement, modals missing role="dialog" + aria-modal + aria-labelledby, missing lang on <html>, broken heading hierarchy
- Icon-only buttons must have aria-label
- Every form field must have a visible <label> or aria-label
- Never remove focus indicators without providing focus-visible styles as a replacement
- When running an a11y audit, always launch it as a background sub-agent — do not block the main conversation
